[8] Para cada ejercicio: (drawings: 0)
[9] Formule las hipótesis: (drawings: 0)
[10] H₀: los promedios de todos los grupos son iguales. (drawings: 0)
[11] H₁: al menos uno de los promedios es diferente. (drawings: 0)
[12] Calcule la media y desviación estándar de cada grupo. (drawings: 0)
[13] Verifique el supuesto de normalidad mediante la prueba de Shapiro–Wilk para cada grupo. (drawings: 0)
[14] Verifique el supuesto de homogeneidad de varianzas mediante la prueba de Levene. (drawings: 0)
[15] Aplique el ANOVA de un factor y determine el estadístico F, los grados de libertad y el p-valor. (drawings: 0)
[16] Tome la decisión estadística considerando la regla: (drawings: 0)
[17] p-valor ≥ α → H₀ (drawings: 0)
[18] p-valor < α → H₁ (drawings: 0)
[19] Si el ANOVA presenta diferencias estadísticamente significativas, aplique una prueba post hoc para determinar entre qué grupos se encuentran las diferencias. (drawings: 0)
[20] Redacte la conclusión e interprete los resultados en el contexto del problema. (drawings: 0)
[21] Importante: el ANOVA permite determinar si existen diferencias significativas entre los promedios de los grupos, pero no identifica directamente entre qué grupos se presentan dichas diferencias. Cuando p-valor < 0,05, deberá complementarse el análisis con una prueba post hoc. Si se cumple la homogeneidad de varianzas, puede utilizarse Tukey; si no se cumple, conviene utilizar Welch como alternativa al ANOVA clásico y Games-Howell para las comparaciones posteriores.
